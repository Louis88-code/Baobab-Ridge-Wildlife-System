# Baobab Ridge Wildlife Rehabilitation Records System

## Project
PRG2782 - Programming Project

## Description
A C# Windows Forms application for managing wildlife rehabilitation records.

## Technologies
- C#
- Windows Forms
- .NET 8.0 or newer
- Git and GitHub
- Text-file storage

## Group Members
Add all five members' names and student numbers here.

## Features
- Add animals
- View animals
- Update animals
- Delete animals
- Generate summary reports

## Build and Run
Open the solution in Visual Studio, build the project, and run it.

## File Formats
- animals.txt: stores animal records.
- summary.txt: stores the generated summary report.

## Error Handling
All exceptions are sent to the `ExceptionHandler` class (`ExceptionHandler.cs`). It shows the user a friendly message and logs the full details to `errors.log` next to the executable.
