OPTION 2 — VIEW ANIMALS AND FILE LOADING

- Updated the target framework to net9.0-windows for compatibility with the Visual Studio version used during local testing.
- Created a simple, editable Windows Forms layout in Form1.Designer.cs.
- Loads animals.txt on form startup and from the Load / Refresh button.
- Displays records in a DataGridView with readable headings and record count.
- Reports missing files, empty files, and invalid records.
- Add, Update and Delete buttons are interface placeholders for other project options and do not modify records in this Option 2 implementation.
